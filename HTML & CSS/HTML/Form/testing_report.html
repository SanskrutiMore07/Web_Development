Kwikza Manual Testing Report

Module: Inventory & Product Catalog
Owner: Sanskruti
1. Menu & Category Listing
Test Scenarios / Test Cases Expected Result Actual Result Pass / Fail Bug Details
Verify total items count matches actual items in shop. Count (e.g., 65 Items) should exactly match the sum of all category items.
Verify category-wise item count. Starter (18), Main Veg (10) etc. should show correct item counts.
Search items using the search bar. Relevant items should filter accurately based on keywords.
Check 'Grid view' and 'List view' toggles. Layout should switch smoothly without breaking UI.
2. Add New Item & Image Uploads
Test Scenarios / Test Cases Expected Result Actual Result Pass / Fail Bug Details
Click '+ Add' button and fill mandatory fields (Category, Item Name). Item should be saved successfully.
Upload product image (up to 8 images, max 10MB). Image should upload, save, and display correctly on the product card.
Try adding an item without selecting a category. System should show error: "Please select an item in the list."
3. Product Variants & Stock Management
Test Scenarios / Test Cases Expected Result Actual Result Pass / Fail Bug Details
Open an item (e.g., Achari Chicken Tikka) and check variants. Variant list should open with correct prices and SKUs.
Search variants by SKU or attributes. Only matching variants should be displayed.
Click 'Mark out of stock' on a variant. Status should immediately update to out-of-stock.
Add a new variant with unique SKU and price. Variant should be saved and variant count should increase.
4. Category Markup & Discounts
Test Scenarios / Test Cases Expected Result Actual Result Pass / Fail Bug Details
Apply a % Markup (e.g., 20%) to a category. All item prices in that category should increase by 20%.
Apply a Flat Amount Discount to a category. Prices should decrease by the exact flat amount.
5. AI Features (Menu & Stock Scan)
Test Scenarios / Test Cases Expected Result Actual Result Pass / Fail Bug Details
Use AI Menu Scan. Should parse physical menu into digital products correctly.
Use AI Menu/Stock scan with insufficient wallet balance. Should block scan and show a clear wallet-recharge prompt.

Cross-Functional Checks (Dependencies)

  • Customer Shop (Komal): After adding/editing a product, check it appears with the right name, price, and image on the customer shop page.
  • POS (Niharika): Newly added items should be available for billing on the POS.
  • Stock Blocking: After marking a product 'out of stock', check it is actually blocked from being added to the cart (Customer Shop) and from being sold on POS.
  • Wallet Deduction (Abhijit): After running an AI scan, check exactly ₹6 (menu scan) or ₹4 (stock scan) is deducted from the wallet balance.
  • Reports (Sakshi): After performing a bulk delete, confirm the deleted items disappear from the live product list as well as the Inventory report.
